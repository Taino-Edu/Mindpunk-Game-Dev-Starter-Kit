# Guia de Contribuição - Mindpunk Lab

Obrigado pelo seu interesse em contribuir com o **Mindpunk Game Dev Starter Kit**! Como um projeto educacional, adoramos receber melhorias na documentação, novos exercícios e, claro, novos jogos.

## Como começar?

1.  **Encontrou um erro?** Abra uma [Issue](https://github.com/Taino-Edu/Mindpunk-Game-Dev-Starter-Kit/issues).
2.  **Tem uma melhoria?** Faça um Fork e envie um Pull Request.

## Nossos Padrões

Para manter a qualidade educacional, pedimos que as contribuições sigam estes critérios:

### 1. Documentação Didática
Se você adicionar código, ele **deve** vir acompanhado de um arquivo `SRC_COMENTADO_xxx`. Não basta o código funcionar; ele precisa ensinar *por que* foi feito assim.

### 2. Estilo de Código
- **Python:** PEP 8.
- **TypeScript:** ESLint padrão.
- **Rust:** `cargo fmt`.

### 3. Exercícios
Sempre que adicionar um novo jogo, inclua pelo menos 3 níveis de exercícios:
- **Nível 1:** Alteração de constantes e valores.
- **Nível 2:** Pequenas mudanças de lógica.
- **Nível 3:** Desafios de manutenção ou refatoração.

## Processo de Pull Request

1.  Certifique-se de que o código está funcionando.
2.  Atualize o `README.md` do projeto afetado se necessário.
3.  O time da Mindpunk Lab irá revisar seu PR em até 48h.

*Mantra: Toda decisão cria. Toda criação custa.*
