Conjunto completo de recursos didáticos para ministrar workshops de desenvolvimento de jogos, desde a teoria de loops até a implementação prática.

---

## 🎓 O Que É

Este módulo contém o material pedagógico utilizado nos workshops presenciais da **Mindpunk Lab** (como o realizado na UNIP). Ele foi projetado para ser uma experiência imersiva de 3 horas, cobrindo os fundamentos teóricos e guiando os alunos na criação do seu primeiro projeto funcional.

---

## 📁 Estrutura do Material

| Componente | Descrição |
|---|---|
| **[Slides](./slides/slides.md)** | Apresentação visual em Markdown (compatível com Marp/Reveal.js). |
| **[Roteiro do Professor](./docs/ROTEIRO_PROFESSOR.md)** | Guia minuto a minuto para o instrutor, incluindo dicas de ensino. |
| **[Material do Aluno](./docs/MATERIAL_ALUNO.md)** | Guia de acompanhamento para os estudantes com exercícios e links. |

---

## 🏫 Tópicos do Workshop

1.  **A Mentalidade Game Dev:** O que diferencia um software comum de um jogo.
2.  **O Game Loop:** Input -> Update -> Render.
3.  **State Management:** Como o computador "lembra" o que está acontecendo no jogo.
4.  **Hands-on:** Implementação do *Deep Sea Coder* ou *Fragmento 01*.
5.  **Desafios:** Exercícios de lógica aplicados ao gameplay.

---

## 🚀 Como Utilizar

1.  **Prepare o Ambiente:** Certifique-se de que os alunos tenham Python ou Node.js instalados conforme o projeto escolhido.
2.  **Apresente os Slides:** Use o material na pasta `/slides`.
3.  **Siga o Roteiro:** O arquivo `ROTEIRO_PROFESSOR.md` contém todas as "colas" necessárias para uma aula fluida.
